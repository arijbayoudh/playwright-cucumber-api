## 📝 Project Description

This project is a **professional API automation framework** using:

- **Playwright API** for making HTTP requests
- **Cucumber** for BDD-style tests
- **TypeScript** for type safety
- **cucumber-html-reporter** for generating HTML reports
- **Retry** mechanism to reduce flaky tests
- **Tagging** (`@smoke`, `@regression`) for selective test execution
- Parallel execution of tests

The target API for this project is: [JSONPlaceholder](https://jsonplaceholder.typicode.com)

## 📁 Architecture du projet

```
playwright-api-cucumber/
│
├── src/
│ ├── core/
│ │ └── apiClient.ts # Playwright API client wrapper
│ ├── services/
│ │ └── posts.service.ts # Service class for /posts API
│ └── config/
│ └── env.config.ts # Base URLs and environment configs
│
├── features/
│ ├── posts.feature # Feature file for Posts API scenarios
│ └── step-definitions/
│ └── posts.steps.ts # Step definitions for posts.feature
│
├── src/scripts/
│ └── generate-report.ts # Script to generate HTML report from JSON
│
├── reports/
│ ├── report.json # Generated by Cucumber
│ └── cucumber-report.html # Generated by cucumber-html-reporter
│
├── package.json
├── tsconfig.json
└── cucumber.js # Cucumber configuration
```

## 🔁 Méthodes API couvertes

✔ GET  
✔ POST  
✔ PUT  
✔ PATCH  
✔ DELETE  

Toutes les méthodes sont encapsulées dans des **services réutilisables**.

---

**Class Responsibilities:**

| Class / File                | Responsibility |
|------------------------------|----------------|
| `ApiClient`                  | Create Playwright APIRequestContext for all API calls |
| `PostsService`               | Encapsulates `/posts` API operations |
| `posts.steps.ts`             | Implements Cucumber steps (`Given`, `When`, `Then`) |
| `generate-report.ts`         | Converts `report.json` to HTML with metadata |
| `env.config.ts`              | Stores environment configuration (base URLs, headers) |

## 🛠️ Installation

Clone the repository:

```bash
git clone <your-repo-url>
cd playwright-api-cucumber
Install dependencies:
```

```bash
npm install
Create reports folder:
```

```bash
mkdir reports
```
--- 

## 🚀 Running Tests
Run all tests:

```bash
npm run test
Run Smoke tests only:
```

```bash
npm run test:smoke
Run Regression tests only:
```
```bash
npm run test:regression
```
--- 

## 📊 Generate HTML Report
After running the tests, generate the report:

```bash
npm run report
Output: reports/cucumber-report.html

Auto-opened if launchReport: true in generate-report.ts
```

--- 

## 🏷️ Tags Usage
@smoke → critical scenarios

@regression → full regression suite

Cucumber can filter scenarios by tags:

```bash
npx cucumber-js --tags @smoke
🔧 Retry & Parallel Execution
Retry 2 times on failure (retry: 2 in cucumber.js)

Run steps in parallel (parallel: 4 in cucumber.js)
```
